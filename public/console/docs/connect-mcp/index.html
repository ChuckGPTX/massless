BUILD WITH CHUCKSI

Connect your AI assistant

Browse Chucksi designs from any compatible remote MCP client.

Your connection

https://console.chucksi.com/mcp

Transport: Streamable HTTP. Authentication: none for the public catalog. This is a live read-only MCP server. It cannot read your account, create media or publish a website.

Claude Code

claude mcp add --transport http chucksi https://console.chucksi.com/mcp
claude mcp list

Then ask: “Use Chucksi to find a website design for a portrait studio. Compare three options, retrieve the best match, and give me its studio link.”

Other MCP clients

Open your client’s remote server or connector settings. Enter the URL above, select HTTP if prompted and leave authentication unset. Connect and list tools. Exact menus and connector availability depend on your client and plan. No Chucksi marketplace plugin or OAuth sign-in is required for these public tools.
