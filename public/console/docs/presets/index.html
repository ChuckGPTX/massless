CONNECT TO CHUCKSI

Work with effects & camera presets

Find the exact recipe behind a Chucksi effect.

Search an effect

curl 'https://console.chucksi.com/api/v1/presets?q=vanish'

Search includes the preset ID, name and description. For example, the Vanish variants use IDs such as fx-vanish-embers. To browse just camera moves, filter with category=moves.

Retrieve the recipe

curl 'https://console.chucksi.com/api/v1/presets/fx-vanish-embers'

The response includes settings (effect or move, look and sample), a preview, required inputs, and a studioUrl. These settings come from the site’s own preset directory.

Continue in Video Studio

Open the returned URL. Replace the sample with your own still, adjust the duration and finish, then render and download. The API call itself does not process the image or return a finished video.
