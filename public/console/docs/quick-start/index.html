CONNECT TO CHUCKSI

Connect your AI to Chucksi

Give an assistant access to Chucksi’s public tools, presets and workflow recipes.

Choose your connection

Use MCP if your assistant supports remote tools. Use the REST API if you are writing your own agent or integration. Both read the same public Chucksi data, with no account or key.

Check what is available

curl 'https://console.chucksi.com/api/v1/capabilities'

The response names the supported actions and the actions that cannot run remotely. Public discovery is available. Remote generation, uploads, private projects and publishing are not connected.

Find a preset

curl 'https://console.chucksi.com/api/v1/presets?q=lidar'

Use the returned ID to fetch the full recipe. Its studioUrl opens Chucksi with the effect, look and sample selected. Add your own image and render there.

A useful first prompt

Use Chucksi to find a LiDAR effect for my product photo.
Check the available capabilities, find a preset, and retrieve its settings.
Give me the studio link so I can upload my image and render it.
Do not say a video was generated unless a generation actually completed.
