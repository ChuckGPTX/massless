Your first Chucksi API request

Get a complete editable design in two requests.

1. Browse the catalog

The public catalog needs no account or API key. It returns 32 complete website starting points.

curl https://console.chucksi.com/api/v1/templates

2. Get a design

curl https://console.chucksi.com/api/v1/templates/echo-festival

The response contains template, site, mediaBase, version and usage. The site is editable data, not rendered HTML.

3. Make it your own

Open Echo Festival in the website studio →. Replace example names, dates, prices and pictures. Preview on desktop and phone, then export. Sign in if you want to publish a subdomain.

Try JavaScript

const response = await fetch(
  'https://console.chucksi.com/api/v1/templates/echo-festival'
);
if (!response.ok) throw new Error(`HTTP ${response.status}`);
const { site, mediaBase } = await response.json();
console.log(site.name, site.pages, mediaBase);

Public catalog responses allow cross-origin reads. Cache repeated reads for five minutes. No requests in this guide run AI or spend generation credits.
