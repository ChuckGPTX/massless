Troubleshooting & limits

Get unstuck without losing your work.

The API returned 404

List the catalog again and copy an exact template ID. Make sure the path starts with /api/v1/templates/.

The API returned 405

The public catalog only supports GET, HEAD and OPTIONS. It does not accept create, edit or publish requests.

MCP tools do not appear

Use the exact https://console.chucksi.com/mcp URL with a client supporting Streamable HTTP. Reconnect, then list tools. Do not choose the old SSE transport or append /sse. A browser Origin rejection means your client’s web origin is not allowed; use a server-side or local MCP client. Contact the project with the client name and origin, never a token.

The website assistant is busy

HTTP 429 means a visitor, shared or provider limit was reached. Wait 30 seconds for a burst limit; daily Chucksi limits reset at midnight UTC. Do not retry repeatedly. Your site is unchanged and manual editing remains available.

A draft could not be used

HTTP 502 means the provider failed, timed out or returned edits outside the supported contract. Try one focused request, such as shortening the headline. A missing provider configuration returns 503. No paid model is substituted.

The site changed before applying

Ask for a new draft. This protects edits you made after the request started. Use Undo after applying a draft if you prefer the earlier version.

Report a problem

Open a GitHub issue with the page URL, time, browser, action and error message. Do not include API keys, cookies, private prompts or customer files.
