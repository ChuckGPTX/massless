CONNECT TO CHUCKSI

Access, limits & troubleshooting

Understand the connection and resolve common errors.

Does connecting share my account?

No. Public MCP and REST discovery do not sign you in or gain access to your private files, drafts, projects or library. There is currently no public API-key dashboard or OAuth connection for those actions.

Can my agent generate media?

Not through this public connection yet. It can find features, retrieve presets and guide you into the correct studio. Check /api/v1/capabilities before advertising any action. Do not treat an example clip as a new generation.

MCP tools do not appear

Use https://console.chucksi.com/mcp with Streamable HTTP. Reconnect and list tools. A normal browser visit may show a protocol error. If a browser client receives an Origin rejection, use a local or server-side MCP client and report the client name and origin to the project.

The API returned an error

404 means the exact ID or path was not found. Fetch the list and retry with a returned ID. 405 means the method is unsupported: public discovery is read-only. 400 means the query exceeds its size limit.

What is free?

Public discovery does not run models or consume generation credits. Studio generation has its own availability and shared limits. Connecting an agent does not remove them or guarantee unlimited hosted inference.

Report a problem

Open a GitHub issue with the URL, time, client, action and error. Never include API keys, cookies, private prompts or customer files. For Website help, use the Website guides.
