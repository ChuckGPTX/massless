CONNECT TO CHUCKSI

Connect tools into workflows

Help an agent choose the steps from an idea to a finished project.

Find a workflow

curl 'https://console.chucksi.com/api/v1/workflows?q=teaser'

Recipes cover music teasers, launch films, image composition, captions, 3D scenes, documents, games and design kits. Each describes the expected output and steps.

Read the steps

curl 'https://console.chucksi.com/api/v1/workflows/release-teaser'

For a music teaser, the recipe points you through creating artwork, adding your track in Music, and exporting there. Each step contains a human-readable name and a working studio URL.

Guide, then hand off

An assistant can collect your brief, compare recipes, explain required files and return the next studio link. The current API does not automatically move private files between tools, execute those steps or save outputs. Those actions stay in the signed-in or local studio experience.
