Create with the AI assistant

Turn a brief into editable changes you control.

From direction to draft

  1. Open Website Studio and choose a design.
  2. In Create, find Your creative partner. Choose this page or a new template draft.
  3. Describe your business, audience and the changes you want. Confirm the sharing notice.
  4. Select Preview AI changes. Review the before-and-after text, then apply or discard.

Applying edits to this page creates one Undo step. If you change the site while a draft is being written, Chucksi asks you to request a fresh draft instead of overwriting your work. A new template draft is a separate project; the previous project is saved on your device.

What it can change

Headlines, descriptions, button labels, page search copy, the brand accent and supported split, centered or cover hero layouts. Only the selected page and site name/tagline are considered. It preserves image files, link destinations, forms, publishing settings and account data. Pricing, reviews, team biographies and similar factual sections are excluded from automatic edits.

It does not write arbitrary scripts, generate images, create new backend functions or publish for you. Replace the remaining example content on every page before launching.

What is sent

Your request and up to 50 editable text/design fields go through Chucksi’s server to OpenRouter and NVIDIA. Uploaded files, image bytes, account tokens, form destinations and other pages are not included. Page text can still contain personal information you wrote; remove sensitive information before requesting changes. The free provider may log inputs and outputs. Chucksi does not persist AI prompts in the request limiter.

Model and limits

The selected model is NVIDIA Nemotron 3.5 Super VL (free). The integration uses an explicit free model ID, zero maximum token prices and no provider fallback. If unavailable, it returns an error; manual editing still works.

Chucksi allows 5 attempts per visitor per UTC day, within a shared 40-attempt daily allowance, with 30 seconds between requests. Failed attempts count. Visitors sharing an internet connection may share a limit. Provider availability and separate provider limits also apply. These caps keep the public feature bounded; they are not a guarantee of unlimited free inference.
