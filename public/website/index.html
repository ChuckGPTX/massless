          Before you publish

            Publish

            Put your site online free at your-name.v2web.site.

            Free, with a small Chucksi badge. Follow the hosting rules.

            Host it free

            Your export is a plain static site, so any static host works. These three are free and need no code. Each also lets you add your own domain later.

            Cloudflare Pages

            1. Download the ZIP.
            2. In the Cloudflare dashboard, open Workers & Pages, choose Create application, then Pages and Drag and drop your files.
            3. Name the project, drop the ZIP (or the unzipped folder) and choose Deploy site.

            Live at your-name.pages.dev. Free plan: up to 1,000 files, 25 MiB each.

            Netlify Drop

            1. Download the ZIP.
            2. Open app.netlify.com/drop.
            3. Drag the ZIP or the unzipped folder onto the page.

            Live at a .netlify.app address in seconds. Without an account it is password-protected until you sign up free and claim it.

            GitHub Pages

            1. Unzip the download.
            2. Create a public repository on github.com/new, choose uploading an existing file, drag in everything inside the folder and commit.
            3. In Settings, Pages: deploy from the main branch, / (root), then Save.

            Live at username.github.io/repository in about a minute. The ZIP includes .nojekyll so GitHub serves it as is.

            Or use Publish for a free your-name.v2web.site address.
